onkooz — Agentic Loop

Automated · Self-running · Reporting for you and your clients

The Loop

Lead comes in → AI validates it → AI scores and routes it → Auto-delivered to client CRM → AI monitors response time → Reminds client if no contact → Weekly reports auto-generated and sent → Billing triggered → Loop repeats. You watch, you don't touch.

The 7 Agents — What Each One Does
🔍
Intake Agent
Trigger: form submitted
  • Verifies email is real (not disposable)
  • Validates phone number format + carrier check
  • Checks for duplicate leads (same phone/email in last 30 days)
  • Rejects and logs bad submissions automatically
Output: Clean lead record saved to Airtable
🧠
Qualification Agent
Trigger: new clean lead
  • AI reads the lead's message/need description
  • Assigns a quality score (1–10) based on specificity
  • Tags the niche (roofing, HVAC, legal, etc.)
  • Flags high-value leads for priority routing
Output: Lead scored + tagged in Airtable
🗺️
Routing Agent
Trigger: lead is scored
  • Matches lead to correct client by niche + zip code
  • Checks if client has capacity (not over monthly limit)
  • If exclusive — assigns to one client only
  • If shared — routes to up to N clients simultaneously
Output: Client(s) assigned to lead record
⚡
Delivery Agent
Trigger: client assigned
  • Pushes contact data to client's CRM via webhook/API
  • Sends client instant SMS + email with lead details
  • Logs delivery timestamp in Airtable
  • Updates lead status → "Delivered"
Output: Lead in client CRM, client notified
⏰
Follow-Up Agent
Trigger: 4 hrs after delivery
  • Checks if client has updated lead status
  • If no action — sends reminder to client automatically
  • At 24hrs — escalates with second reminder
  • At 48hrs — flags for your review (bad client alert)
Output: Client response rate tracked
📊
Reporting Agent
Trigger: weekly / monthly schedule
  • Pulls all lead data from Airtable
  • Generates your internal report (all clients)
  • Generates per-client report (their leads only)
  • Emails reports automatically — no manual work
Output: Reports sent to you + each client
💳
Billing Agent
Trigger: lead delivered / end of month
  • Counts billable leads delivered per client
  • Deducts any approved bad-lead credits
  • Generates and sends invoice via Stripe/email
  • Flags unpaid invoices after 7 days
Output: Invoice sent, revenue tracked
