Table Relationships
Leads → Clients many-to-one
Leads → Niches many-to-one
Clients → Niches many-to-many
Delivery Log → Leads many-to-one
Delivery Log → Clients many-to-one
Billing → Clients many-to-one
Audit Log → Leads many-to-many
Reports → Clients many-to-one (nullable)
Clients → Clients self-ref backup
Which Agent Reads / Writes Which Table
🔍 Intake Agent
Reads: Leads (dup check), Token Usage
Writes: Leads (new row), Audit Log (if rejected)
🧠 Qualify Agent
Reads: Leads, Niches (keywords), Token Usage
Writes: Leads (quality_score, score_reason, niche), Token Usage
🗺️ Route Agent
Reads: Leads, Clients (niche, zip, cap, status)
Writes: Leads (assigned_client, status→Routed)
⚡ Deliver Agent
Reads: Leads, Clients (webhook_url)
Writes: Leads (status, delivered_at), Delivery Log
⏰ Follow-Up Agent
Reads: Leads (delivered_at, followup_count), Clients
Writes: Leads (followup_count, status), Clients (response_rate)
📊 Report Agent
Reads: Leads, Clients, Billing, Token Usage, Niches
Writes: Reports (new row per client + internal)
💳 Billing Agent
Reads: Leads (billing_id, status), Clients (price, stripe_id)
Writes: Billing (invoice), Leads (billing_id if null)
🎛️ Management Agent
Reads: All tables — monitors status fields
Writes: Leads (escalated, escalation_reason), Audit Log
🚦 Token Police
Reads: Token Usage, Leads (record count)
Writes: Token Usage (daily row), Audit Log (if budget alert)
🔴 Red Team Agent
Reads: Leads, Delivery Log, Billing, Token Usage
Writes: Audit Log, Leads (quarantined flag)
Lead Status Flow — All Possible Values
New → Validated → Scored → Routed → Delivered → Contacted → Closed ✓ or Lost
Rejected Unrouted Delivery Failed Quarantined Escalated Archived
